## はじめかた

**1. 教材をクローンする**

作業用フォルダで、次のコマンドを実行します。

```sh
git clone https://github.com/GenerativeAgents/claude-code-book-v2.git
cd claude-code-book-v2
```

**2. 読んでいる章のフォルダを開く**

下の一覧から、書籍で読んでいる章の README を開きます。必要なツールや、どの節で何をコピーするかは章ごとに異なります。

**3. 書籍の手順に沿って進める**

このリポジトリの中で、すべての演習をそのまま実行するわけではありません。章で別の作業用リポジトリを作る場合は、教材から必要なファイルだけをそちらへコピーします。

## 章から探す

教材は章ごとに `chapter-XX/` へまとめます。リンクのある章から利用できます。

| 章 | 収録教材 |
| :-- | :-- |
| [第4章 バイブコーディング実践でアプリを狙いどおり作る](chapter-04/README.md) | 要件・設計のエージェントスキル例、コミット前・デプロイ前のフックと設定 |
| 第2・3・5・6章ほか | このリポジトリでは未収録 |

## 困ったときは

- まず、各章の README と書籍の該当節で、作業ディレクトリとファイルの配置を確認してください。
- 教材の不具合は [Issues](https://github.com/GenerativeAgents/claude-code-book-v2/issues) へ。章・節番号、OS、Claude Code のバージョン、再現手順があると確認しやすくなります。認証情報や非公開のログは添付しないでください。
- 初版の教材を探している場合は [初版『実践Claude Code入門』のリポジトリ](https://github.com/GenerativeAgents/claude-code-book) を参照してください。
